# Nullion v0.11.0

Nullion v0.11.0 improves research, browser reliability, and everyday chat responsiveness.

- Complete related tool operations together with optional Code Mode while keeping permissions and confirmations in place.
- Preserve verified findings, links, dates, and generated files through long requests and recovery.
- Read independent pages together and avoid repeating completed research.
- Keep quoted billing periods separate from actual trip duration when comparing prices.
- Reconnect to the saved desktop browser, preserve pages you ask to keep open, and close temporary research tabs after each request.
- Produce clearer PDF reports and sharper infographic images, with useful error messages when generation cannot finish.
- See compact progress updates for searches, page reads, and other completed work.
- Keep saved location defaults for local requests, even after discussing a trip elsewhere.
- Receive faster acknowledgements and more reliable replies and attachments across chat surfaces.
