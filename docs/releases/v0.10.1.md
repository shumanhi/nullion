# Nullion v0.10.1

Nullion v0.10.1 improves report completion and generated-file delivery.

- Receive useful answers and available reports when another part of a request
  cannot finish, with a specific explanation of what remains unavailable.
- Get the selected final files instead of working copies or duplicate attachments.
- Resume approved work with its existing findings, files, and requested media
  requirements intact.
- Keep native permissions, account-source choices, and delivery confirmations
  in place while avoiding unnecessary answer-review delays and retry cycles.
- See clear file-generation failures instead of an attachment confirmation when
  the requested file was not created.
- Keep a generated file reply as one message after reload, even when its
  attachment caption changes during delivery.
- Preserve the first message you send while chat history is still loading.
- Keep the original image in context when replying to an earlier image message,
  including when its first request was interrupted.
