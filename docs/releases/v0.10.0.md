# Nullion v0.10.0

Nullion v0.10.0 adds temporary live tracking and improves how ongoing work,
scheduled reports, and generated files reach you.

- Watch a changing source until a chosen end time, with frequent checks,
  alerts for new results, and clear controls to update or stop tracking.
- Keep follow-up details, selected options, and saved profile defaults attached
  to the request they belong to.
- Resume approved work with its completed findings and files instead of
  starting the whole request again.
- Receive useful answers and valid reports when an optional review cannot
  finish, with specific limitations when requested work remains incomplete.
- Get more consistent, concise presentation across chat, reports, alerts, and
  status messages, using your saved timezone and clock preference.
- Receive the selected final files with clearer delivery status and fewer
  duplicate messages or attachments.
- Recover more reliably from browser and connection failures, with clearer
  next steps when a source or configured provider is unavailable.

Existing recurring jobs remain available. Live tracking requires an accessible
source and a finite end time; image generation requires a configured provider
with sufficient credits.
